# All The Games I've Ever Suggested

Every game TechDweeb has recommended on YouTube, video by video, plus a stats overview.

**Live site:** https://eeman1113.github.io/techdweeb-games/

- 129 videos (83 recommendation lists + 46 Dusty Game Society reviews)
- 969 game shout-outs, 704 different games
- Search any game, filter by system/year, see every video it appears in
- Stats: most recommended games, retro vs modern, systems, views analysis, trends over time

Game names come from video chapters and transcripts, data up to Nov 24, 2026.

## Files
- `index.html`, `styles.css`, `app.js`: the site (no build step)
- `data.js`: all videos, games and stats
- `data/*.csv`: raw data (every video on the channel, every game per video)
- `assets/`: images from [techdweeb.straw.page](https://techdweeb.straw.page)

Built by Eeman Majumder for [TechDweeb](https://www.youtube.com/@TechDweeb).
